# TaxBackKR

## Platform
앱인토스 (Vite + React + TDS)

## One-liner
연말정산·종합소득세 환급액을 30초 안에 시뮬레이션하고, 절세 팁을 리워드 광고 뒤에 공개하는 세금 환급 계산기

## Problem
대부분의 직장인과 프리랜서가 연말정산·종합소득세 신고 시즌마다 환급액 예측을 못 하고, 홈택스는 너무 복잡해서 포기한다. 절세 방법도 알기 어렵다.

## Target Users
20-40대 직장인, 프리랜서, N잡러. 특히 연간 소득 2,000만~8,000만원 구간의 토스 주요 유저층.

## Core Features
1. 연봉·소득 유형(직장인/프리랜서/N잡) 입력 → 예상 환급액/추가납부액 즉시 계산
2. 리워드 광고 시청 후 절세 항목별 상세 분석 공개 (신용카드·의료비·교육비 공제)
3. 공제 항목 조정 슬라이더로 환급액 변화 실시간 시뮬레이션
4. 종합소득세 신고 대상 여부 자동 판단 (프리랜서·부업 수입 입력)
5. 절세 체크리스트 (IRP·연금저축·의료비 한도 등) 달성도 표시
6. 매년 1-5월 시즌 알림 및 작년 데이터 localStorage 저장 비교

## Monetization
- Model: ads
- Estimated MRR: 4200000
- Reasoning: 절세 상세 분석을 리워드 광고 뒤에 게이팅. 세금 시즌(1-5월) DAU 3,500 추정, 비시즌 1,200. 연평균 DAU 1,800 기준: 리워드 수익 1,800×0.2×30×4/1000×1350×0.85 = 약 247만원/월. 배너 수익 1,800×2×30×1/1000×1350×0.85 = 약 124만원/월. 시즌 피크 월 2배 반영 연평균 약 420만원/월.
